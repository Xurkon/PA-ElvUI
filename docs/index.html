PA-ElvUI Monorepo v1.3.8

This repository hosts the tailored ElvUI distribution for Project Ascension.

Included Modules

  • ElvUI: Core addon.
  • ElvUI_Enhanced: QoL improvements (Patched for OmniBar compatibility).
  • ElvUI_AddOnSkins: Skins for other addons.
  • ElvUI_OptionsUI: Configuration interface.

Developer Notes

OmniBar Compatibility

ElvUI_Enhanced has been modified to support the latest PA-Omnibar structure. It now correctly iterates over OmniBar.bars instead of looking for a nil OmniBar.icons table.
